# Autoria de splats do Lumon

Os módulos em `src` vêm de [pixelart-gaussiansplat](https://github.com/cobanov/pixelart-gaussiansplat/tree/67662968b0837b2180b22989be70980fc3b97321), sob a [licença MIT](LICENSE). Esta cópia registra a versão usada pelo exportador, incluindo a adaptação local em `light.js` que permite desligar a quantização durante a pintura. Apenas os módulos consumidos pelos geradores do Lumon acompanham o jogo.
